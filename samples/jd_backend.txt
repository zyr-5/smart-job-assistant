职位名称：Python 后端开发工程师

公司名称：上海智云科技股份有限公司
工作地点：上海·浦东新区
薪资范围：25K - 40K · 14薪
经验要求：3-5 年
学历要求：本科及以上

职位描述
我们正在寻找一位经验丰富的 Python 后端开发工程师，加入核心业务研发团队，负责 SaaS 平台后端服务的设计、开发与优化。你将与产品、前端及运维团队紧密协作，参与高并发系统的架构演进。

岗位职责
1. 负责核心业务 API 的设计、开发与维护，保障服务稳定性与性能
2. 使用 FastAPI 或同类框架构建 RESTful 接口，编写清晰的技术文档
3. 进行 MySQL 数据库设计与 SQL 优化，处理慢查询与索引调优
4. 使用 Redis 实现缓存、分布式锁、限流等方案
5. 参与消息队列（RabbitMQ / Kafka）与异步任务（Celery）相关开发
6. 编写单元测试与集成测试，参与 Code Review
7. 配合 DevOps 完成 Docker 容器化部署与 CI/CD 流程

任职要求
1. 本科及以上学历，计算机相关专业
2. 3 年以上 Python 后端开发经验，有完整项目交付经验
3. 熟练掌握 FastAPI、Flask 或 Django 中至少一种 Web 框架
4. 熟悉 MySQL，具备索引优化、事务、分库分表实践经验
5. 熟练使用 Redis，了解缓存策略与常见数据结构应用场景
6. 熟悉 Linux 环境，了解 Docker 容器化部署
7. 具备良好的编码习惯、沟通能力与团队协作精神

加分项
- 有高并发、高可用系统设计与优化经验
- 熟悉 Elasticsearch、ClickHouse 等数据分析组件
- 有 LLM / AI 应用后端集成经验
- 了解 Go 语言或微服务架构（gRPC、服务治理）

福利待遇
五险一金、带薪年假、弹性工作、技术培训、年度体检、下午茶
