职位名称：前端开发工程师（Vue 方向）

公司名称：深圳前端科技有限公司
工作地点：深圳·南山区
薪资范围：18K - 30K · 13薪
经验要求：2-4 年
学历要求：本科及以上

职位描述
我们是一家专注于 B 端 SaaS 产品的互联网公司，现招聘前端开发工程师（Vue 方向），负责管理后台、数据可视化及移动端 H5 的前端开发。团队技术氛围开放，鼓励技术分享与工程化实践。

岗位职责
1. 基于 Vue 3 + TypeScript 开发企业级管理后台与业务模块
2. 使用 Element Plus / Ant Design Vue 等 UI 库，封装可复用业务组件
3. 与后端对接 RESTful API，处理复杂表单、表格、权限与状态管理
4. 使用 Pinia / Vuex 进行全局状态设计，保障数据流清晰可维护
5. 参与前端工程化建设：Vite 构建优化、ESLint 规范、组件库维护
6. 优化页面性能（懒加载、虚拟列表、打包体积），提升用户体验
7. 配合产品、设计完成需求评审与技术方案输出

任职要求
1. 本科及以上学历，计算机或相关专业
2. 2 年以上前端开发经验，有 Vue 项目完整交付经验
3. 精通 Vue 2/3 及其生态（Vue Router、Pinia/Vuex、Composition API）
4. 熟练使用 TypeScript，具备良好的类型设计能力
5. 熟悉 HTML5、CSS3，能独立实现响应式布局与主流浏览器兼容
6. 熟悉 Axios 等 HTTP 库，有 RESTful 接口对接经验
7. 了解 Webpack 或 Vite 等构建工具，有前端工程化实践经验
8. 代码规范意识强，注重可维护性与团队协作

加分项
- 有 React / Next.js 项目经验，可参与多技术栈项目
- 熟悉 ECharts 等数据可视化库
- 有微前端（qiankun / Module Federation）实践经验
- 了解 Node.js 或微信小程序开发
- 有性能优化、无障碍（a11y）实践经验

福利待遇
五险一金、双休、弹性打卡、技术书籍报销、团建活动、节日礼品
