职位名称：Java 高级架构师

公司名称：北京金融云创集团
工作地点：北京·朝阳区
薪资范围：50K - 80K · 16薪
经验要求：10 年以上
学历要求：硕士及以上（985/211 优先）

职位描述
金融云创集团是国内领先的金融科技解决方案提供商，服务于银行、保险、证券等头部金融机构。现招聘 Java 高级架构师，负责核心交易系统的架构设计、技术选型与团队技术引领，主导大型分布式系统的规划与落地。

岗位职责
1. 主导金融级核心交易系统（日交易量 10 亿+）的整体架构设计与演进
2. 制定 Java 技术栈规范，主导 Spring Cloud / Dubbo 微服务治理体系建设
3. 负责高可用、高一致性分布式架构设计（CAP 权衡、分布式事务 TCC/Saga）
4. 带领 15+ 人技术团队，进行架构评审、代码审查与技术人才培养
5. 对接 CTO 制定三年技术路线图，评估并引入新技术（Service Mesh、云原生）
6. 参与重大客户项目投标与技术方案撰写，主导 POC 与上线保障
7. 建立完善的监控告警、容灾演练与应急响应机制

任职要求
1. 硕士及以上学历，计算机相关专业，985/211 院校优先
2. 10 年以上 Java 开发经验，5 年以上大型系统架构设计经验
3. 精通 Java 核心技术（JVM 调优、多线程、并发编程、设计模式）
4. 深度掌握 Spring Boot、Spring Cloud、MyBatis、Dubbo 等主流框架
5. 熟悉 Oracle / DB2 等企业级数据库，有金融核心库设计与调优经验
6. 精通分布式系统理论：一致性协议、服务发现、熔断降级、限流
7. 有银行、证券、保险等金融行业核心系统架构经验（必须）
8. 具备 PMP 或同等项目管理认证者优先
9. 有技术团队管理经验，优秀的跨部门沟通与汇报能力

技术栈要求（必须项）
- 语言：Java 17+（不接受 Python / Go 为主栈背景转岗）
- 框架：Spring Cloud Alibaba、Dubbo 3.x、ShardingSphere
- 中间件：RocketMQ、Zookeeper、Nacos、Seata
- 数据库：Oracle 19c、TiDB、HBase
- 基础设施：Kubernetes、Terraform、私有云部署
- 安全合规：等保三级、PCI-DSS、国密算法改造经验

加分项
- 发表过架构相关技术专利或顶会论文
- 有央行、银保监会相关项目合规经验
- 熟悉量化交易或风控引擎架构

说明
本岗位为高级管理技术岗，要求候选人具备金融行业背景与 Java 生态深度积累。纯互联网背景、后端语言以 Python/Node 为主者暂不合适。
